Tradeoffs

What v0.1 doesn't do yet, and why — the credibility page. If it's not here or in the README status line, assume it works as described.

Learning is post-run, not mid-run

The distiller mines finished runs on an interval (default 30s). A run in progress streams its error and tool-call events to the console live feed as they happen, but there's no automatic mid-run correction and no pitfall-warning callback yet — the SDK doesn't inspect a run's own errors against known lessons while it's still open. That's the single biggest gap against hosted runtimes that intervene inside a call.

No token compression

Injected memory/lesson content is capped by the SDK (APOIDEIA_INJECT_MAX_TOKENS, default 1500) but the cap is a blind character-prefix cut, not value-aware — it can slice a memory mid-word rather than dropping the lowest-value content first. It's never summarized or compressed either. Injection adds tokens to a call — the console's savings panel shows that overhead rather than hiding it.

Retrieval backend, honestly

The memory engine's built-in lexical/adaptive retriever serves recall by default. It scores IDF-weighted token overlap against the agent's own store, so a term shared by every memory contributes nothing and a rare one dominates — and the trace carries the per-token weights, so a ranking can be inspected rather than trusted.

Measured: 85.3% precision@5 against a 270-memory store, across the eval suite. The 15% it misses are the queries a token-overlap retriever structurally cannot serve — a claim reading "policy inception 2017" against a rule phrased "written before 2019" shares no terms at all. Those show up directly as an accuracy ceiling on the page (prior authorization, our weakest family, is recall-bound at 58.3%). Semantic matching is the fix, and it exists: the retrieval engine integration (vector/hybrid/rerank routing with an explainable strategy trace) is real, wired, and tested — but its local embedding model downloads from Hugging Face on first use, so it's off by default in network-restricted environments. Set APOIDEIA_RETRIEVER=engine where that's reachable.

Single region, no HA

v0.1 is one gateway process, one Postgres, one memory-engine instance. Horizontal scaling needs the Postgres LISTEN/NOTIFY bridge noted in the architecture doc in place of the current in-process event bus — straightforward, not yet built.

No orchestration

Apoideia is deliberately not an agent framework or orchestrator. Bring your own agent loop in whatever framework you like; Apoideia is the memory/learning/observability layer underneath it.

Recall latency budget

The SDK gives recall 500ms before failing soft and skipping injection. On a cold cache or a loaded gateway that can mean an occasional call runs without injected context rather than blocking your latency-sensitive path. The Python SDK logs that at DEBUG on the apoideia logger; the TypeScript SDK does not log it at all, so there it is currently indistinguishable from memory having had nothing to say.
